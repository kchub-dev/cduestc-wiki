# AI 助手「本地直连」使用说明

Wiki 右下角的 AI 助手默认走「校园网关」。如果你想要**更快、更稳、由自己账号生成**的回答，可以安装我们的浏览器扩展「科成星球 AI 直连助手」，把聊天切换到**本地直连**模式。

简单说：**网站还是零后台零成本，AI 请求从你自己的浏览器发出、用你自己登录的豆包或 DeepSeek 账号，回答只发给你自己。**

## 它是怎么工作的

```
科成星球 Wiki（纯静态网站）
   │  把你的问题 + 检索到的知识片段拼成一段话
   ▼
浏览器扩展（装在你电脑上）
   │  用你自己浏览器里已登录的账号发请求
   ▼
豆包网页版 / DeepSeek 网页版（你自己的账号）
```

- 知识库检索照旧在网页本地完成，扩展只负责「替你把这段话发给你自己的 AI 账号」。
- 扩展**不收集**任何浏览记录，权限只限豆包、DeepSeek 两个网站的网络访问。
- **豆包 / DeepSeek 模式**都会自动管理一个后台通道页（第一次使用时自动创建，不抢焦点、不打断你，请勿关闭；关掉后下次提问会自动重建）：豆包通过它发送请求，DeepSeek 通过它读取登录凭证（读到后立即关闭）。Windows 上通道页运行在隐藏窗口里，**完全无感**；macOS 浏览器限制更严，表现为标签栏最左侧一个钉住的小图标（不会跳页、不会弹窗）。

## 支持哪些浏览器

| 浏览器 | 支持情况 |
| --- | --- |
| **Microsoft Edge**（电脑版） | ✅ 推荐。Windows 电脑自带；未来上架微软商店后可直接一键安装 |
| **Google Chrome**（电脑版） | ✅ 支持 |
| 其他 Chromium 内核浏览器（360 极速、QQ 浏览器等） | ⚠️ 一般可用，需能打开「扩展管理」页 |
| 手机浏览器 / Safari / Firefox | ❌ 不支持，手机上请继续用默认的校园网关模式 |

## 安装步骤（约 2 分钟）

::: tip 第一步：下载扩展压缩包
**[点我下载 cduestc-ai-extension.zip](/downloads/cduestc-ai-extension.zip)**（约 30 KB）

本站直连下载，**不需要 GitHub、不需要外网梯子**。下载后解压，会得到一个 `cduestc-ai-extension` 文件夹。
:::

1. 把下载的压缩包**解压**到电脑上任意位置（如桌面），得到 `cduestc-ai-extension` 文件夹。
2. 打开**电脑版**浏览器，地址栏输入：Edge 输 `edge://extensions`，Chrome 输 `chrome://extensions`。
3. 打开页面上的「**开发者模式**」开关（在右上角或左下角）。
4. 点击「**加载解压的扩展程序**」（Edge）/「**加载已解压的扩展程序**」（Chrome），选择第 1 步解压出来的 `cduestc-ai-extension` 文件夹。
5. 在**同一个浏览器**里登录 [chat.deepseek.com](https://chat.deepseek.com) 或 [www.doubao.com](https://www.doubao.com)（用哪家登哪家）。提问时扩展会自动打开对应的后台通道标签页；如果还没登录，在那个页面里登录一次即可。
6. 回到科成星球 Wiki，点开右下角 AI 助手，点标题栏的「**网关**」按钮切换成「**直连**」。

之后提问就会由你自己的账号回答，回答会**逐字显示**出来。

::: info 为什么需要"开发者模式"？
浏览器为了安全，不允许网站给用户静默安装扩展——这是所有浏览器共同的硬限制。我们正在把扩展上架到**微软 Edge 加载项商店**，上架审核通过后即可像普通扩展一样**一键安装**（点链接 → 点「获取」），也不用再手动更新。上架进度会更新在这一页。
:::

## 常见问题

**切换直连时提示「未检测到扩展」？**
确认扩展已在 `chrome://extensions` 里启用、没有报错；然后刷新 Wiki 页面再试。

**直连模式下提示「未找到登录凭证 / 登录已失效」？**
重新登录豆包或 DeepSeek，并**打开一次它的页面**（扩展需要从页面拿一次登录凭证），再回到 Wiki 重新提问。

**想换默认上游（DeepSeek / 豆包）？**
点浏览器工具栏里的扩展图标，在弹窗里选择默认上游、开关 DeepSeek「深度思考」（R1 模式，回答更细致但更慢），也能查看登录状态。在 Wiki 聊天窗标题栏里也能直接切换。

**直连提问时会不会多出窗口 / 标签页？**
直连模式需要一个对应站点的后台页面来工作（豆包的请求要由真实页面发出，DeepSeek 的登录凭证要从页面读取），扩展会把这个页面藏起来：
- **Windows / Linux**：运行在后台隐藏窗口里，不会出现任何可见窗口或标签页，**完全无感**；
- **macOS**：浏览器不允许程序化隐藏窗口，退而求其次——标签栏最左侧出现一个**钉住的小图标**（不抢焦点、不会跳转），DeepSeek 的凭证页则读完立即关闭。
请不要关闭豆包的小图标，关掉后下次提问会自动重建。

**扩展以后怎么更新？**
重新下载本页顶部的压缩包，解压覆盖原来的文件夹，然后到 `edge://extensions`（或 `chrome://extensions`）点一下扩展卡片上的「刷新 / 重新加载」即可（这一步必须做，否则浏览器可能仍在用旧的代码）。上架微软商店后将自动更新，不用再手动操作。

**手机上能用吗？**
暂不支持。手机浏览器的扩展生态不成熟，手机上请继续使用默认的校园网关模式。

**两套模式冲突吗？**
不冲突。校园网关是默认模式，随时点标题栏按钮切回；两者互不影响。

## 风险说明

- 自动化使用豆包 / DeepSeek 网页版**可能违反其用户协议**，账号理论上存在被限制的风险。请仅作个人学习用途，不要高频刷题或用于商业用途。
- 上游网页改版可能导致直连暂时不可用，届时切回校园网关即可，扩展维护者会跟进适配（见仓库 `extension/README.md`）。
