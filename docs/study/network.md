# 学院之网

::: warning **重要说明**
学院之网（校园网）是学校提供的网络服务，需要在校园网覆盖区域内使用。
:::

## 如何使用学院之网

### 1. 获取学校企业钉钉账号

入学后，学校会为你开通**学校企业身份的钉钉账号**。这是使用学院之网的前提条件。

### 2. 申请校园网账号

通过学校企业身份的钉钉账号，按照学校流程申请**校园网账号**。

### 3. 连接校园网

申请成功后，前往以下地点连接校园网：
- 教室
- 图书馆
- 其他校园网覆盖区域

### 4. 登录之网

在校园网环境下，即可登录**之网**系统。

::: tip **温馨提示**
确保你在校园网覆盖区域内，才能正常使用学院之网服务。
:::
